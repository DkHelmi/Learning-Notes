# CTI

Catatan saya belajar cyber threat intelligence dari sudut pandang analyst SOC dan IR, ditulis dalam Bahasa Indonesia. Isinya berjalan dari siklus intelijen dan PIR, analytic tradecraft, dan framework seperti Kill Chain, Diamond, dan ATT&CK, sampai mengolah IOC dengan MISP dan OpenCTI, membaca profil aktor, menulis produk CTI, vulnerability intelligence, dan konteks berbagi informasi di Indonesia. Contohnya memakai organisasi fiktif, dengan rujukan ke sumber seperti MITRE, FIRST, CISA, dan dokumentasi resmi alat yang dipakai.
