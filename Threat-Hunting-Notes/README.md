# Threat Hunting

Catatan saya belajar threat hunting berbasis hipotesis dari sudut pandang analyst SOC, ditulis dalam Bahasa Indonesia. Isinya berjalan dari metodologi dan cara menulis hipotesis, data dan baselining, hunting di Splunk, Wazuh, dan Velociraptor, ke perburuan per taktik seperti persistence, credential access, lateral movement, dan C2, sampai mengubah temuan menjadi deteksi, hunting identitas dan cloud, serta program hunt. Rujukannya ke MITRE, SANS, dan dokumentasi resmi alat yang dipakai.
