# Security Fundamentals

Catatan saya merangkum istilah dan konsep dasar cyber security yang sering muncul di pekerjaan SOC dan saat interview, ditulis dalam Bahasa Indonesia dengan bahasa yang sederhana. Isinya berjalan dari fondasi keamanan dan jaringan dasar, kontrol jaringan seperti firewall, IDS, IPS, dan WAF, DDoS, kriptografi, endpoint dan identitas, Active Directory, cloud, email, operasi SOC dan triage, indikator dan threat intel, kerangka serangan, jenis serangan dan malware, kerentanan, GRC, sampai dasar incident response. Rujukannya ke NIST, RFC, OWASP, MITRE, CISA, dan dokumentasi resmi vendor.
