# Network Forensics

Catatan saya belajar forensik jaringan dari sudut pandang analyst SOC yang juga lama di NOC dan ISP, ditulis dalam Bahasa Indonesia. Isinya berjalan dari Wireshark dan analisis protokol, anomali DNS, HTTP, dan TLS, ke Zeek, Suricata, dan flow, sampai pola beaconing, C2, exfiltration, lateral movement lewat SMB dan Kerberos, serta tantangan baru seperti ECH, DNS terenkripsi, dan log jaringan cloud. Rujukannya ke RFC, dokumentasi resmi Zeek, Suricata, dan Wireshark, serta MITRE.
