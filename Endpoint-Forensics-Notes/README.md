# Endpoint Forensics

Catatan saya belajar forensik endpoint dari sudut pandang responder, ditulis dalam Bahasa Indonesia, terutama untuk Windows dan memori dengan tambahan Linux dan macOS. Isinya berjalan dari alur kerja DFIR dan triage dengan KAPE dan Velociraptor, artefak eksekusi, file system, registry, dan aktivitas pengguna, ke super-timeline dan analisis memori dengan Volatility 3, sampai pelaporan, anti-forensics, dan korelasi lintas host. Rujukannya ke dokumentasi resmi alat, Microsoft, SANS, dan NIST.
