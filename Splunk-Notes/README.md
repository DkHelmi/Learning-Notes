# Splunk

Catatan saya belajar Splunk dari sudut pandang analyst SOC, ditulis dalam Bahasa Indonesia. Isinya berjalan dari cara Splunk menyimpan dan mencari data, SPL untuk triage, dan membaca log Windows, Linux, jaringan, serta cloud, sampai data model, Enterprise Security, risk-based alerting, hunting, dan SOAR. Contohnya memakai satu organisasi fiktif dan dataset publik seperti BOTS, dengan rujukan ke dokumentasi resmi Splunk, Lantern, dan research.splunk.com.
